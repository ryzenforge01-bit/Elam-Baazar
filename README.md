🌿 Elam Bazar – Cardamom Auction Platform

Elam Bazar V1.0 is a B2B multi-platform auction ecosystem designed specifically for the cardamom trading market, enabling farmers, sellers, and buyers to participate in transparent, real-time auctions.

The platform introduces a Live Trade Room experience, allowing multiple users to place bids simultaneously with instant updates, ensuring fairness, accuracy, and high performance across devices.

🚀 Key Features
🔴 Live Auction System
Real-time bidding powered by WebSockets, ensuring instant updates without page refresh.
⏱️ Smart “Soft Close” Timer
Auction time automatically extends (10s reset logic) to prevent last-second bid sniping.
📊 Seller & Admin Dashboards
Dedicated web dashboards for managing auctions, monitoring bids, and tracking transactions.
📱 Cross-Platform Mobile App
Built using React Native (Expo) for seamless performance on both Android and iOS.
🔐 Secure Financial Data Handling
PostgreSQL with Supabase ensures ACID-compliant transactions and reliable data integrity.
🏗️ Tech Stack
Frontend (Mobile): React Native (Expo)
Web (Admin & Seller): Next.js
Backend: Supabase (PostgreSQL)
Real-time Engine: WebSockets
Serverless Functions: TypeScript Edge Functions
💡 Project Vision

Elam Bazar aims to digitize and modernize the traditional cardamom auction process, making it more transparent, efficient, and accessible. By leveraging real-time technologies, the platform ensures a fair trading environment where every participant has equal opportunity.
